# Data and ChromaDB

The current Digiwise notebook expects an **already-created ChromaDB vector store**.

## Supported locations

- Google Colab: `/content/drive/MyDrive/chromadb_vectorstore`
- Local: `./data/chromadb_vectorstore`
- Custom: set `VECTOR_STORE_PATH`

Example:

```bash
export VECTOR_STORE_PATH="/path/to/chromadb_vectorstore"
```

PowerShell:

```powershell
$env:VECTOR_STORE_PATH="C:\path\to\chromadb_vectorstore"
```

## Why it is not included

The current project does not establish that the vector store is small enough, licensed for redistribution, or reproducibly generated by a documented pipeline. Therefore it is not presented as part of this repository.

A future ingestion pipeline should document:

- source documents
- preprocessing
- chunking
- embedding model
- ChromaDB creation
- reproduction steps

Do not commit private, confidential, or unlicensed source documents.
